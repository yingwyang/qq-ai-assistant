## 一、产品简介

**铃音 QQ 对话** 是一款跨端智能聊天辅助系统，能够：

- 通过 NapCat 实时监听 QQ 群聊 / 私聊消息
- 将消息持久化到本地 MySQL 数据库
- 借助 AstrBot 对群聊记录进行 AI 总结、情感分析、关键词提取
- 支持图片、语音、视频、@消息、回复消息、合并转发消息等多种消息类型
- 提供多用户、多 QQ 绑定、权限隔离等能力

## 二、快速开始

### 2.1 启动服务

推荐使用以下顺序启动：

1. **MySQL**：确保数据库已启动并执行过 `backend/src/main/resources/init-mysql.sql`
2. **AstrBot**：启动 AI 服务（默认端口 `6185`）
3. **NapCat**：启动 QQ 机器人框架
4. **后端**：运行 `java -jar backend/target/qq-ai-assistant-1.0-SNAPSHOT.jar`
5. **前端**：在 `frontend` 目录执行 `npm run dev`，默认打开 `http://localhost:5173`

### 2.2 首次登录

打开前端页面后，使用默认管理员账号登录：

- 用户名：`admin`
- 密码：`admin123`

> 首次登录后建议立即修改密码并绑定 QQ 号。

## 三、登录与账号

### 3.1 用户登录 / 注册

- 未登录时，左侧边栏显示 **登录** 按钮
- 点击后输入用户名和密码登录
- 无账号可联系管理员创建，或根据系统配置自行注册

### 3.2 绑定 QQ 号

1. 登录后点击左侧头像进入 **个人信息**
2. 找到 **QQ 绑定** 区域
3. 输入要绑定的 QQ 号并提交
4. 绑定成功后，系统只会展示该 QQ 号所在群聊的消息

> 一个系统账号可绑定多个 QQ 号，消息按 QQ 号隔离。

### 3.3 修改头像与昵称

在个人信息页可以：

- 上传自定义头像（支持裁剪预览）
- 修改昵称
- 设置默认 QQ 绑定

## 四、群聊消息

### 4.1 查看群聊列表

登录后，左侧边栏会按 **QQ 绑定分组** 展示群聊：

- 每个 QQ 号下显示其加入的群聊
- 群聊按最后一条消息时间倒序排列
- 未读消息数会显示在群聊右侧（0 不显示，≤99 显示数字，>99 显示 `99+`）

### 4.2 进入群聊

点击任意群聊即可加载该群消息。进入群聊时：

- 会自动将该群标记为已读
- 消息列表默认滚动到底部（最新消息）
- 向上滚动可加载更多历史消息

### 4.3 消息类型

系统支持以下消息渲染：

| 类型 | 展示方式 |
|------|----------|
| 文本 | 普通文本，支持 Markdown 与自动链接 |
| 图片 | 缩略图，点击可放大预览 |
| 视频 | 视频播放器 |
| 语音 | 音频播放器（AMR 已自动转 MP3） |
| @消息 | 自动解析为 `@昵称`，无昵称时显示 `@QQ号` |
| 回复消息 | 显示引用的原文 + 回复内容 |
| 合并转发 | 折叠为 `[聊天记录]` 卡片，点击展开 |

### 4.4 消息选择与分析

1. 点击群聊顶部的 **选择** 按钮进入选择模式
2. 点击消息左侧复选框进行选择
3. 可选择 **最近 N 条** 快速批量选中
4. 点击 **分析** 按钮，将选中的消息发送给 AstrBot
5. AI 助手会自动生成总结、话题分析等内容

> 转发的聊天记录会提取内部文本，AI 可以直接阅读；分析结果会以可折叠面板展示在 AI 对话框中。

## 五、AI 助手

### 5.1 发起新对话

点击 AI 助手面板顶部的 **新对话** 按钮即可创建空白会话。

### 5.2 查看对话历史

点击 **对话历史** 按钮，可查看、切换、删除历史会话。

### 5.3 AI 回复操作

每条 AI 回复下方有两个按钮：

- **复制**：将 AI 回复的纯文本复制到剪贴板
- **语音生成**：占位按钮，后续版本将支持将文本转为语音

### 5.4 AI 回复格式

AstrBot 的回复支持丰富的 Markdown 渲染：

- 标题、列表、加粗、斜体
- 代码块、引用
- 表格、自动链接
- 可折叠摘要卡片
- 章节导航（当内容包含多个标题时自动生成目录）

## 六、右键删除群消息

在左侧群聊列表的任意群聊上 **点击右键**，可打开删除菜单：

- 删除图片消息
- 删除视频消息
- 删除音频 / 语音消息
- 删除文本消息
- 删除聊天记录（合并转发）
- 删除所有消息

### 删除规则

- 删除为 **软删除**，数据库记录保留，仅标记为已删除
- 图片 / 视频 / 音频 / 语音类型的消息会 **同时删除本地媒体文件**
- 只能删除当前登录用户绑定的 QQ 号所接收的消息
- 删除后会立即刷新群聊列表和消息视图

## 七、媒体管理

管理员可进入 **系统管理 → 媒体文件管理**：

- 按类型筛选：全部 / 图片 / 视频 / 音频 / 文件
- 预览图片 / 视频
- 单选 / 全选 / 批量删除本地媒体文件
- 查看总数量、总大小、已选数量、已选大小

> 删除媒体文件会同步软删除引用该文件的消息。

### 8.1 组件控制

系统管理面板提供以下组件的启动 / 停止：

管理员可在后台：

- 修改用户角色（ADMIN / USER）
- 启用 / 禁用账号
- 删除用户

## 九、常见问题

### Q1：登录后看不到群聊

- 请确认已绑定 QQ 号
- 确认 NapCat 已登录且该 QQ 号已加入目标群聊
- 检查后端日志确认消息已被接收并入库

### Q2：AI 回复为空或异常

- 确认 AstrBot 服务已启动且可访问
- 检查后端配置 `astrbot.api-url` 和 `astrbot.token`
- 同一对话中，若历史消息过多，可尝试新建对话

### Q3：图片 / 视频无法显示

- 检查 `backend/uploads` 目录下文件是否存在
- 检查浏览器控制台是否有 404 错误
- 如文件已物理删除，界面会显示 `图片已删除` / `视频已删除` 占位

### Q4：语音无法播放

- 语音文件（SILK / AMR）会自动转码为 MP3
- 如转码失败或文件被删除，点击播放时会提示 `音频已删除`

### Q5：删除消息后页面崩溃

- 请确保图片 / 视频 / 音频组件的 URL 不为空
- 已删除媒体的占位图会自动替换，避免无效请求
