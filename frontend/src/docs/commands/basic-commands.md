# 基本命令

QQ AI 助手提供了一系列基本命令用于群聊管理。

## 用户命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/help` | 显示帮助信息 | `/help` |
| `/status` | 查看机器人状态 | `/status` |
| `/clear` | 清除对话上下文 | `/clear` |

## 管理员命令

以下命令仅限管理员使用：

| 命令 | 说明 | 示例 |
|------|------|------|
| `/ban @用户` | 禁言指定用户 | `/ban @张三` |
| `/unban @用户` | 解除禁言 | `/unban @张三` |
| `/kick @用户` | 踢出群聊 | `/kick @张三` |
| `/mute` | 开启全员禁言 | `/mute` |
| `/unmute` | 关闭全员禁言 | `/unmute` |

## 消息管理

- `/msg count` — 查看今日消息统计
- `/msg search <关键词>` — 搜索历史消息
- `/msg delete <类型>` — 删除指定类型消息

> **提示**：使用 `/help <命令名>` 可以查看单个命令的详细用法。
