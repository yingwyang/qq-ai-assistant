# AI 对话命令

通过以下命令可以与 AI 进行交互。

## 基础对话

| 命令 | 说明 | 示例 |
|------|------|------|
| `/ai <内容>` | 发送消息给 AI | `/ai 你好` |
| `/ai reset` | 重置 AI 对话上下文 | `/ai reset` |
| `/ai model` | 查看当前使用的模型 | `/ai model` |
| `/ai model <名称>` | 切换 AI 模型 | `/ai model gpt-4` |

## 角色扮演

| 命令 | 说明 |
|------|------|
| `/role list` | 列出可用角色 |
| `/role set <名称>` | 设置 AI 角色 |
| `/role clear` | 清除角色设置 |

## 语音功能

| 命令 | 说明 |
|------|------|
| `/tts on` | 开启语音回复 |
| `/tts off` | 关闭语音回复 |
| `/tts voice <音色>` | 切换 TTS 音色 |
| `/stt` | 语音转文字（回复一条语音） |

## 图片识别

| 命令 | 说明 |
|------|------|
| `/vision` | 开启/关闭图片识别模式 |
| `/vision describe` | 描述最近一张图片 |

> **注意**：语音和图片识别功能需要对应插件已启动。
