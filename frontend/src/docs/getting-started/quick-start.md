这一页是**最短路径**：不解释原理，只按顺序点。走完这 6 步，你就能看到真实的 QQ 群消息、用 AI 分析群聊、和 AI 对话，并领到第一笔积分。

## 开始前确认三件事

1. 有人已经把这套系统部署好，并且你知道前端地址（本机部署通常是 `http://localhost:5173`）。
2. 你有一个能登录的账号：管理员账号 `admin`（密码在首次启动日志里），或者自己注册一个。
3. 机器人 QQ 号已经在 NapCat 里扫码登录（否则群里没有任何消息可看）。

> 提示：登录页左侧的「系统状态」卡片会列出平台后端与 NapCat / AstrBot / GPT-SoVITS 的运行状态。显示「未运行」时先别急着往下走，先看 [系统配置](system-config)。

## 第 1 步：注册 / 登录

1. 打开前端地址，进入登录页。左侧是能力清单与系统状态，右侧是登录卡。
2. 有账号：填写「请输入账号」「请输入密码」，点击 **登 录**（也可以直接按 `Enter` 提交）。
3. 没账号：点击 **立即注册**，填写账号、昵称（选填）、密码、确认密码后点击 **注 册**。
4. 如果这是你自己的设备，勾选 **记住我（30 天免登录）**，之后 30 天内不用反复登录。
5. 登录成功后进入主页：左边是群聊列表，中间是消息区，右边是 AI 面板。

注册字段的硬性要求（后端校验，填错会被拒绝）：

| 字段 | 要求 |
|------|------|
| 账号 | 必填，**3~20 个字符**，不允许重名 |
| 昵称 | 选填，留空时自动用账号作为昵称 |
| 密码 | 必填，**8~64 位**，且必须同时包含大写字母、小写字母与数字 |
| 再次输入密码 | 必填，需与密码一致 |

> 提示：注册受「开放注册」开关控制，若提示「注册暂未开放」，请让管理员创建账号或开启注册。同一 IP 每分钟最多提交 5 次注册请求；同一 IP + 账号每分钟最多尝试登录 5 次。

> 提示：密码忘了不用急。点登录页的 **忘记密码？**，按弹窗提示联系管理员，管理员在 **管理后台 → 用户管理** 点「重置密码」即可。详见 [个人中心与账号安全](account)。

## 第 2 步：绑定你的 QQ 号（关键一步）

**不绑定就看不到任何消息**——系统只展示你绑定过的 QQ 号所收到的群消息。

1. 点击左侧侧边栏底部的头像/用户名，进入 **用户中心**。
2. 切到 **个人信息** 标签页，找到 **QQ绑定** 区域。
3. 点击 **添加绑定**，弹出「绑定QQ账号」窗口。
4. 输入你的 QQ 号（5~11 位数字），点击 **发送验证码**。
5. 系统会通过机器人向该 QQ 号发送一条**私信验证码**。打开手机 QQ，在该号码（机器人）的聊天窗口里看它发来的消息，取 6 位验证码。
6. 把验证码填进「请输入6位验证码」，点击 **确认绑定**。
7. 绑定成功后，回到主页，左侧「最近对话」里就会出现这个 QQ 号所在的群聊。

| 规则 | 说明 |
|------|------|
| 验证码有效期 | 5 分钟，过期需重新发送 |
| 验证码长度 | 6 位数字 |
| 发送频率 | 每个 QQ 号每天最多 10 次；发送后界面有 60 秒倒计时 |
| 唯一性 | 一个 QQ 号只能被一个账号绑定 |
| 多绑定 | 一个账号可以绑定多个 QQ 号，消息按 QQ 号分组 |

> 提示：提示「该QQ号已被其他用户绑定」时，先确认这个号有没有被同事/朋友绑过；确实需要换绑，请联系管理员处理，不要重复尝试。

## 第 3 步：进入群聊看消息

1. 左侧「最近对话」按 **QQ 绑定分组**展示群聊，点击任意群即可加载消息。
2. 群名右侧的数字是未读数：1~99 显示数字，超过 99 显示 `99+`。
3. 进入群聊会自动标记已读，消息列表默认滚到最新一条。
4. 往上滚动可以加载更早的历史消息（出现「加载更早的消息...」表示正在拉取）。
5. 群聊列表会自动刷新，新消息会实时推送进来。

看到的媒体（图片/视频/语音）是后端异步下载的结果，刚收到时可能还是占位提示，稍等片刻刷新即可。若长期是 `[视频已过期]` 这类提示，见 [消息与媒体](messages)。

## 第 4 步：让 AI 分析选中的消息

AI 摘要**不是自动生成的**，需要你手动发起：

1. 在群聊顶部点击 **选择消息** 按钮，进入选择模式。
2. 勾选你想分析的几条消息；也可以填个数量后点 **选择最近** 批量选中（旁边的 **清空** 用于取消选择）。
3. 点击 **AI 分析**，弹出「选择分析维度」窗口。

| 分析维度 | 产出什么 |
|----------|----------|
| 群聊速览 | 群主题 / 氛围 / 近期热点，快速了解群在聊什么 |
| 社交图谱 | 活跃人物 / 意见领袖 / 话题带动者，知道谁是关键人 |
| 话题趋势 | 上升 / 稳定 / 衰退话题，把握参与时机 |
| 融入指南 | 参与建议 / 共同兴趣 / 避雷提示（核心维度，带「推荐」标记） |
| 梗词典 | 群内特有梗 / 缩写 / 表情含义，看懂黑话 |
| 人设匹配 | 形象定位建议 / 发言风格参考，塑造受欢迎的人设 |

4. 想补充要求时，在下方的「补充说明（可选）」里写一句，例如 `重点分析图片内容` 或 `我刚进群，帮我找共同话题`（最多 500 字）。
5. 点击任意维度即开始分析，结果会以 Markdown 面板展示在右侧 AI 区域。

> 提示：弹窗顶部会显示「当前群类型」，推荐维度会高亮并标记「推荐」。群类型设置见 [群聊接入与群类型](group-setup)。

## 第 5 步：和 AI 对话

1. 右侧 AI 面板顶部点 **新对话**，创建空白会话。
2. 直接在底部输入框提问，AI 会结合当前群聊语境回答，回复支持 Markdown（标题、列表、代码块、表格、可折叠摘要）。
3. 点 **对话历史** 可以切换、删除历史会话。
4. 每条 AI 回复下面都能 **复制** 纯文本；点 **语音生成** 可以用 GPT-SoVITS 把这段回复合成为语音并播放（需要已启动 GPT-SoVITS）。

AI 对话按 Token 消耗积分，余额不足时会直接提示，先签到或购买积分即可。详见 [AI 对话与人格](ai-chat) 与 [积分体系](credits)。

## 第 6 步：签到领积分

1. 进入 **用户中心**，切到 **用量管理**。
2. 顶部横幅会显示「欢迎使用积分体系 · 每日签到 +150」（数字以后台配置为准）。
3. 点击 **立即签到**，按钮会变为 **今日已签**，积分实时到账。
4. 横幅下方的「总可用积分 / 累计收入 / 累计支出 / 当前订阅」和「用量明细」可以查看每一笔积分的来去。

| 你能拿到的积分 | 数值 |
|----------------|------|
| 新人注册赠送 | 默认 500（仅首次） |
| 每日签到基础分 | 默认 150（每天一次） |
| 小月卡每日签到额外 | +100 |
| 大月卡每日签到额外 | +300 |
| 小月卡 + 大月卡双持 | +400（叠加） |

## 5 分钟速查表

| 步骤 | 在哪里 | 大约耗时 |
|------|--------|----------|
| 注册 / 登录 | 登录页 | 1 分钟 |
| 绑定 QQ 号 | 用户中心 → 个人信息 → QQ绑定 | 1~2 分钟（等验证码） |
| 进入群聊 | 左侧「最近对话」 | 10 秒 |
| AI 分析 | 群聊顶部「选择消息」→「AI 分析」 | 30 秒 |
| AI 对话 | 右侧 AI 面板 →「新对话」 | 30 秒 |
| 签到 | 用户中心 → 用量管理 →「立即签到」 | 10 秒 |

## 卡住了怎么办

| 现象 | 最可能的原因 | 看哪一篇 |
|------|--------------|----------|
| 登录后左侧群聊列表是空的 | 还没绑定 QQ 号 | 本页第 2 步 |
| 群聊有了，但没有新消息 | NapCat 未登录 / Webhook 未配置 | [系统配置](system-config) |
| 图片、语音显示占位提示 | 媒体体积超限或 QQ 侧原片已过期 | [消息与媒体](messages) |
| AI 分析没反应 | AstrBot 未启动，或积分不足 | [AI 摘要](ai-summary) |
| 提示积分不足 | 余额不够，或账号被限制消费 | [积分体系](credits) |
