# 系统配置

在开始使用 QQ AI 助手前，需要进行一些基础配置。

## 管理员账户

首次启动系统时会自动创建初始管理员账户：

- 用户名：`admin`
- 密码：启动日志中打印的随机密码；也可在 `.env` 中通过 `ADMIN_INIT_PASSWORD` 预先指定

> **安全提示**：请在首次登录后立即修改初始密码。

## 主题设置

系统支持浅色和深色两种主题模式：

1. 点击侧边栏底部的用户信息区域
2. 选择"主题"菜单
3. 切换"浅色模式"或"深色模式"

主题设置会自动保存，下次登录时自动恢复。

## 页面刷新

系统支持全页面自动刷新机制：

- **跨页面导航**：点击导航菜单切换页面时自动刷新数据
- **同路由点击**：再次点击当前已激活的导航项也会触发刷新
- **手动刷新**：页面内操作按钮点击后自动更新对应数据

## 数据概览

数据概览页面提供以下统计信息：

| 统计项 | 说明 |
|--------|------|
| 总消息数 | 系统记录的所有消息总数 |
| 今日消息 | 今日收到的消息数量 |
| AI 对话数 | AI 参与回复的对话数量 |
| 活跃用户 | 今日活跃的用户数量 |
| 消息时段分布 | 今日各时段消息量柱状图 |
| AI 对话趋势 | 近7天 AI 对话数量趋势 |

## 依赖服务

系统运行依赖以下服务：

| 服务 | 端口 | 说明 |
|------|------|------|
| MySQL 8.0 | 3306 | 数据持久化 |
| RabbitMQ | 5672 / 15672 | 消息队列 / 管理界面 |
| NapCat API / WebUI | 6100 / 6099 | QQ 协议端 |
| AstrBot | 6185 | AI 对话引擎 |
| GPT-SoVITS | 8000 | 语音合成服务 |
