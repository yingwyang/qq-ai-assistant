# 欢迎使用铃音QQ对话

铃音QQ对话是一个跨端智能聊天辅助平台，帮助你管理 QQ 群聊、AI 对话、媒体与语音。

## 核心功能

- **QQ 消息管理**：实时接收群聊 / 私聊消息，支持图片、语音、视频、@、回复、合并转发
- **AI 对话与总结**：接入 AstrBot 与大模型提供商，支持多选消息智能分析、人格管理
- **积分与订阅**：每日签到、Token 计费、多档订阅套餐与订单管理
- **语音能力**：SILK / AMR 自动转 MP3，集成 GPT-SoVITS 文本转语音（TTS）
- **媒体管理**：图片 / 视频 / 语音统一管理，支持批量清理
- **数据统计**：消息趋势、AI 对话趋势、积分流水等图表
- **消息队列**：基于 RabbitMQ 的异步媒体下载、语音转码与 AI 分析

## 快速开始

1. 使用账号登录系统（初始管理员 `admin` 的密码在首次启动日志中打印；也可注册新账号）
2. 在个人信息中绑定自己的 QQ 号（需验证码验证）
3. 配置 NapCat / AstrBot 组件
4. 开始浏览群聊消息并与 AI 对话

> 提示：建议先阅读 [系统配置](system-config) 了解依赖服务与基础设置。
