铃音 QQ 对话（QQ AI 助手）是一套**自建的 QQ 群聊 AI 助手平台**：它把机器人在 QQ 群里看到的消息存进自己的数据库，在你自己的网页端统一查看，并按需调用 AI 做摘要、对话和语音合成。数据、积分与订阅都掌握在部署者手里，不依赖任何第三方托管服务。

## 这是一套什么系统

把 QQ 群的消息接进来 → 存下来 → 用 AI 处理 → 在网页端呈现，是这套系统的主线。它不是 QQ 官方的功能，而是通过 **NapCat（OneBot 11 协议）** 登录一个机器人 QQ 号，把该号所在群/收到的消息实时上报给后端，再由后端完成落库、媒体下载和 AI 调用。

系统面向两类人：

| 角色 | 能做什么 |
|------|----------|
| 普通用户 | 绑定自己的 QQ 号、查看群聊消息与媒体、按需生成 AI 摘要、与 AI 对话、用签到与月卡获得积分 |
| 管理员 | 在管理后台管理用户、重置密码、调账、补单、审批退款与纠纷、启停外部组件、查看日志与审计 |

## 核心能力清单

| 能力 | 说明 | 在哪用 |
|------|------|--------|
| QQ 消息接入 | NapCat 通过 Webhook 实时上报群消息，后端去重后落库到 MySQL | 自动，无需操作 |
| 媒体自动下载 | 图片、视频、语音、文件异步下载到服务器；SILK/AMR 语音自动转 MP3 | 自动，失败会留占位符 |
| 群类型识别 | 按最近消息样本让 AI 判断群属于游戏/学习/工作/兴趣/生活/社交/其他 | 群聊设置里的「AI 识别」 |
| AI 摘要 | **按需生成**的结构化摘要：标签 tags + 一句话 summary + 情感 sentiment | 群聊页面手动触发 |
| AI 对话 | 网页端多模型对话，支持上下文与会话历史 | 主页右侧 AI 面板 |
| 人格设置 | 自定义系统提示词，让 AI 用指定身份说话 | AI 面板的「智能体/人格」 |
| TTS 语音合成 | 接入 GPT-SoVITS，把 AI 回复合成为语音播放 | AI 回复下方的「语音生成」 |
| 积分体系 | 新人赠送、每日签到、月卡加成；AI 对话/分析/TTS 按规则消耗 | 用户中心「用量管理」 |
| 月卡订阅 | 小月卡、大月卡、全功能版（双持），支持订单、退款与纠纷申诉 | 用户中心「订阅管理」 |
| 管理后台 | 13 个页面：数据概览、用户、组件控制、媒体、日志、配置、数据维护、积分规则、用户积分、积分流水、订单、退款审批、纠纷处理 | `/admin`（仅 ADMIN） |

## 整体工作流程

一条 QQ 群消息进入系统后，大致会经历这样一段旅程：NapCat 把消息上报到后端 → 后端校验上报令牌并按消息 ID 去重 → 消息原文入库到 MySQL → 图片/视频/语音/文件任务投递到 RabbitMQ 异步下载与转码 → 你在网页端看到这条消息。**AI 摘要不再随消息入库自动触发**（那样每条消息都要花一次模型额度），而是由你在需要时手动发起。

```
 QQ 群消息
    │
    ▼
 NapCat（OneBot 11，6100）──Webhook + 上报令牌──▶ 后端（8081）
    │                                              │
    │                                    ① 去重、② 消息入库（MySQL 3306）
    │                                              │
    │                                    ③ 媒体任务投递（RabbitMQ 5672）
    │                                              │
    │                                    ④ 下载图片/视频/文件，SILK→MP3
    ▼                                              │
 网页端（5173）◀──查询/WebSocket 推送───────────────┘
    │
    ├─▶ 查看消息与媒体
    ├─▶ 手动触发 AI 摘要 ──▶ AstrBot（6185）──▶ tags / summary / sentiment
    ├─▶ AI 对话 / 人格 ────▶ AstrBot（6185）
    └─▶ 语音生成 ─────────▶ GPT-SoVITS（8000）
```

> 提示：AI 与语音都是**可选**能力。只装 MySQL + RabbitMQ + NapCat + 后端 + 前端，消息浏览已经可用；需要摘要和对话再加 AstrBot，需要语音再加 GPT-SoVITS。

## 开始之前

1. **有一个能登录的账号**：管理员账号是 `admin`（密码在首次启动日志里，或由 `ADMIN_INIT_PASSWORD` 指定），也可以自行注册普通账号。
2. **绑定你自己的 QQ 号**：只有绑定后，网页端才会展示该 QQ 所在群聊的消息。绑定需要验证码验证。
3. **机器人 QQ 号已登录 NapCat**：群消息来自机器人账号，不是你的个人账号。
4. **外部依赖已启动**：MySQL、RabbitMQ 是后端启动的硬依赖，缺一个后端就起不来。

## 遇到问题先看这三处

| 现象 | 先看 |
|------|------|
| 完全看不到群消息 | 是否已绑定 QQ 号 → NapCat 是否在线（6100）→ 后端日志有没有收到上报 |
| 图片/视频/语音显示占位提示 | 见 [消息与媒体](messages)，多为体积超限或 QQ 侧原片已过期 |
| AI 无响应 / 提示积分不足 | AstrBot 是否在线（6185）→ 积分余额是否充足 → 见 [AI 摘要](ai-summary) |
