# 欢迎使用 QQ AI 助手

QQ AI 助手是一个功能强大的智能对话管理平台，帮助你管理 QQ 群聊、AI 对话、媒体处理等。

## 核心功能

- **智能对话**：接入主流 AI 模型，实现自动回复和群聊管理
- **媒体处理**：支持语音转文字、文字转语音等多媒体能力
- **多插件支持**：AstrBot、NapCat、GPT-SoVITS 等多种插件
- **数据统计**：实时消息统计、活跃分析、趋势图表
- **消息队列**：基于 RabbitMQ 的异步消息处理，确保高可用性

## 快速开始

1. 登录系统
2. 配置 NapCat 连接
3. 添加 AI 模型
4. 开始对话

> 提示：建议先阅读 [快速入门](getting-started) 了解基本操作。
