这一页解决两个问题：**为什么有的群在列表里、有的不在**，以及**怎么告诉 AI「这是个什么群」**，让分析结果更有针对性。

## 群是怎么被发现的

群不需要手工添加，系统**从消息里自动发现**：

1. 机器人 QQ 号（NapCat 登录的那个号）必须在目标群里。
2. 群里有人发言，NapCat 把消息上报给后端。
3. 后端在保存这条消息的同时，记录该群的群号、群名与归属 QQ（群信息首次出现即入库，之后有新消息会刷新群名）。
4. 网页端左侧「最近对话」拉取的就是这些群，**按你绑定的 QQ 号分组**展示。
5. 列表每 5 秒自动刷新一次，未读数实时更新。

因此有一条铁律：**没有消息的群不会出现在列表里**。刚建的空群、机器人刚加入还没人说话的群，都要等第一条消息进来。

群列表里每一项包含：群头像、群名（取不到时显示「群聊 <群号>」）、群号、所属 QQ 号、最近一条消息时间、未读消息数（1~99 显示数字，超过显示 `99+`）。列表按最近消息时间倒序排列；**群类型不是「其他群」时**，群名旁会额外显示一个类型迷你标签。

## 群不显示？按这个顺序查

| 检查项 | 怎么确认 |
|------|----------|
| 你绑定该 QQ 号了吗 | 用户中心 → 个人信息 → QQ绑定，列表里要有这个 QQ |
| 机器人 QQ 在群里吗 | 用机器人号打开该群，或让群友发一条消息看是否上报 |
| NapCat 在线吗 | NapCat WebUI（`http://127.0.0.1:6099`）显示已登录 |
| Webhook 配好了吗 | 见 [系统配置](system-config) 的 NapCat Webhook 一节 |
| 群里真的发过消息吗 | 让群友发一条纯文本消息，再刷新列表 |
| 是否只发过私聊 | **私聊消息不入库**，只有群消息会被记录 |

> 提示：只有「群消息」会被记录。私聊、撤回、戳一戳这类事件系统会直接丢弃，不会入库。

## 群类型的 7 个选项

| 类型 | 适用场景 | 界面上推荐的 AI 维度 |
|------|----------|----------------------|
| 游戏群 | 讨论游戏攻略、组队、赛事、版本更新 | 梗词典 / 融入指南 / 速览 |
| 学习群 | 科目学习、课程答疑、作业讨论、资源分享 | 速览 / 话题趋势 / 融入指南 |
| 工作群 | 项目讨论、任务分配、职场沟通协作 | 速览 / 融入指南 / 社交图谱 |
| 兴趣群 | 动漫、运动、音乐、手工等兴趣爱好 | 梗词典 / 人设匹配 / 速览 |
| 生活群 | 家庭、邻里、日常琐事、生活经验分享 | 融入指南 / 话题趋势 / 速览 |
| 社交群 | 闲聊交友、聚会活动、拓展人脉 | 社交图谱 / 人设匹配 / 融入指南 |
| 其他群 | 暂时无法归类或混合主题的群 | 速览 / 融入指南 |

> 提示：群类型不是必填项。不设置时按「其他群」处理，AI 依然能分析，只是少了针对性。

## 手动设置群类型

1. 在左侧「最近对话」里，用**鼠标右键**点击目标群聊。
2. 在弹出的菜单顶部选择 **设置群类型（AI 融入）**。
3. 弹窗「群类型设置」会显示当前类型，以及 7 张类型卡片（每张都标了推荐维度）。
4. 点击你想设置的那张卡片（卡片会被高亮勾选）。
5. 点击 **保存选择**，提示「已设置为「学习群」」即成功。

弹窗底部三个按钮的含义：

| 按钮 | 作用 |
|------|------|
| 取消 | 关闭且不保存 |
| 采用识别结果 | 把 AI 识别出的类型填为待保存值（仅在识别过、且识别结果与当前类型不同时出现） |
| 保存选择 | 保存高亮的那张卡片；与当前类型相同时按钮不可点 |

保存后，群列表里的类型标签会立即更新。同一群号如果被你绑定的多个 QQ 都记录过，这次设置会对它们**一起生效**。

> 提示：种类选择是**按群号**保存的，不是按 QQ 号。若刚保存后消息区分析弹窗里的「当前群类型」没变，重新打开一次弹窗或刷新页面即可看到最新值。

## 让 AI 自动识别群类型

不知道选哪一类时，让 AI 判断：

1. 同样右键群聊 → **设置群类型（AI 融入）**。
2. 点右下角的 **AI 识别群类型**（按钮会变成「识别中...」）。
3. 识别完成后，弹窗里会显示三样东西：

   - **识别结果**：AI 判断的类型（带图标标签）
   - **置信度**：例如 `置信度 82%`
   - **判断依据**：AI 给出的理由

4. 认可结果就点 **采用识别结果**，再点 **保存选择**；不认可就直接手动选一张卡片。

识别规则（写在这里省得你反复试）：

| 规则 | 说明 |
|------|------|
| 识别依据 | 该群的 50 条消息样本（昵称 + 内容，单条超长会截断） |
| 结果缓存 | 识别结果可缓存 24 小时；但界面上每次点「AI 识别群类型」都会强制重新识别，不会复用旧结果 |
| 失败处理 | 识别失败**不写缓存**，可以立刻重试 |
| 积分消耗 | **识别成功才扣 1 积分**，失败不扣（管理员账号免费） |
| 积分不足 | 会提示「积分不足（需要 N 积分），无法执行 AI 识别」 |
| 无消息的群 | 返回「其他群」，判断依据为「群聊无消息，无法判断」 |
| 样本偏差 | 群消息非常多时，样本可能取到的是较早的一批内容，识别结果可能落后于群的现状；多发几条新消息后再试更准 |

## 群类型如何影响 AI

群类型不是装饰，它实实在在改变 AI 的输出：

1. **AI 对话的角色定位**：按群类型注入不同的系统提示词。例如游戏群会强调「帮你理解群里的游戏梗和黑话」，学习群强调「提供学习建议和参与讨论的切入点」，工作群强调「职场沟通建议和协作切入点」。未设置的群使用通用提示词。
2. **分析维度的推荐**：AI 分析弹窗（群聊顶部「选择消息」→「AI 分析」）会根据群类型把合适的维度标上 **推荐** 并高亮，弹窗副标题还会显示「（当前群类型：学习群）」。
3. **分析提示词模板**：部分群类型有专属的分析模板（例如游戏群有专门的「游戏梗词典」「游戏群融入顾问」，学习群有「学习话题趋势」，社交群有「社交群人际图谱」「社交群人设顾问」）；没有专属模板的类型会自动降级到通用模板，不会失败。

> 提示：群类型只影响**提示词风格与推荐顺序**，不会限制你能选哪些分析维度——7 个维度任何时候都能手动选。

## 群聊上的右键菜单还有什么

同一个右键菜单里还挂着消息清理功能，按群维度批量删除：

| 菜单项 | 效果 |
|--------|------|
| 删除图片消息 / 删除视频消息 / 删除音频/语音消息 / 删除文本消息 / 删除聊天记录 | 按类型软删除该群的消息，媒体类型会同时删除本地媒体文件 |
| 删除所有消息 | 软删除该群全部消息 |
| 删除群聊 | **硬删除**：清掉该群在该 QQ 下的全部消息、媒体文件、群记录与已读状态，**不可恢复** |

> 提示：这些删除都只针对**你绑定的那个 QQ 号**下的数据。删除群聊属于不可逆操作，执行前请确认该群确实不再需要（比如已经退群）。

## 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 右键没有反应 | 需要在群聊列表项上右键，不是在消息区右键 |
| 识别总返回「其他群」 | 群消息太少或内容太杂；多发几条有实质内容的消息后重试 |
| 识别失败并提示 AstrBot 相关错误 | AstrBot 未启动或令牌不对，见 [系统配置](system-config) |
| 换了类型但分析结果没变化 | 类型只影响提示词风格；重新发起一次分析才会生效 |
| 双持多个 QQ 时群名重复 | 列表按 QQ 分组，同一群号在不同 QQ 下会各显示一次，属正常现象 |
