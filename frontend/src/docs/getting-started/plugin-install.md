# 插件安装指南

QQ AI 助手支持多种插件，以下是各插件的安装与配置说明。

## NapCat

NapCat 是 QQ 协议端，用于连接 QQ 服务。

### 安装步骤

1. 在管理后台点击「插件管理」
2. 找到 NapCat 插件卡片
3. 点击「启动」按钮
4. 等待状态变为「运行中」

### 配置说明

- **端口**：默认 3000，可根据需要修改
- **Token**：用于 API 鉴权，请妥善保管
- **WebSocket**：支持正向和反向 WebSocket 连接

## AstrBot

AstrBot 是 AI 对话核心引擎。

### 安装步骤

1. 确保 NapCat 已正常运行
2. 在插件管理中启动 AstrBot
3. 配置 AI 模型 API Key
4. 选择需要启用的 AI 模型

### 支持的模型

- OpenAI GPT 系列
- Claude 系列
- 通义千问
- 文心一言
- 自定义 API 端点

## GPT-SoVITS

GPT-SoVITS 提供语音合成（TTS）能力。

### 安装步骤

1. 在插件管理中启动 GPT-SoVITS
2. 上传参考音频文件
3. 配置模型参数
4. 在对话设置中启用语音回复

> **注意**：GPT-SoVITS 需要 GPU 支持，建议在独立服务器上部署。

## 自动启动

登录系统后，已配置的插件会自动检查并启动：

- 登录成功后延迟 3 秒自动检查插件状态
- 发现未运行的插件会自动启动
- 登出时会自动停止所有运行中的插件

> **提示**：也可以在「插件管理」页面手动启停插件。
