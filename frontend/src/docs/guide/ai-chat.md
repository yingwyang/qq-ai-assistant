这一页讲网页端的 AI 对话：在哪聊、怎么选模型、上下文怎么算钱、人格（系统提示词）在哪里配、语音合成怎么用。

## AI 面板在哪

| 设备 | 入口 |
|------|------|
| 电脑（宽屏） | 页面**右侧栏**就是 AI 对话面板；收起后点标题为「展开 AstrBot 聊天框」的按钮重新展开 |
| 平板 | 顶部按钮 **AI助手 →** 进入，**← 返回群聊** 返回消息区 |
| 手机 | 底部标签切换：**群聊** / **AI助手** |

面板标题显示当前助手名称（默认「AstrBot 助手」），右侧有 **在线 / 离线** 状态指示——它来自 `GET /api/astrbot/status`，离线时任何对话都不会成功。

### 顶栏看什么

AstrBot 面板顶部一栏，从左到右：

| 位置 | 内容 | 说明 |
|------|------|------|
| 头像 | 机器人头像 + 右下角小圆点 | 绿点=在线、红点=离线 |
| 名称 | 机器人名字（设置里可改） | 旁边绿色胶囊是在线状态；生成回复时会多一个「生成中」胶囊 |
| 副标题 | 当前会话名（没有会话时显示当前群名） | 过长会省略号截断，鼠标悬停看全名 |
| 语音角色 | 🎵 + 角色下拉 | 只有配置了 TTS 角色时才出现；面板拖窄时自动让位 |
| 右侧按钮组 | 对话历史 ｜ 新对话、设置 | 齿轮里是「提供商配置」与「人格与状态」两个面板 |

> 面板宽度可拖动（中间的拖动条）。拖到 470px 以内先藏副标题、430px 以内再藏语音角色，
> 但**名字与在线状态始终保留**。

## 发起对话

1. 点面板顶部的 **新对话**，创建一个空白会话。
2. 在底部输入框提问，发送后等待回复。
3. 回复支持 Markdown 渲染：标题、列表、加粗、代码块、引用、表格、自动链接、可折叠摘要；内容含多个标题时会自动生成章节导航。
4. 每条回复下方提供：

   | 按钮 | 作用 |
   |------|------|
   | 复制 | 把回复的纯文本复制到剪贴板 |
   | 语音生成 / 播放语音 | 用 GPT-SoVITS 合成语音并播放（见下文） |
   | 转发到群 | 把这条文字直接发到某个 QQ 群（见下文「把回答转发到群聊」） |

5. 点 **对话历史** 可以查看、切换、归档、删除历史会话。

> 提示：会话标题会在首轮对话后自动生成（取你第一条消息的前 30 个字），所以不用自己命名。

## 模型怎么选

系统支持多模型切换，选择优先级是：

1. 你在本次对话里**手动指定的模型**（在模型下拉里选的）；
2. 否则用你在设置里保存的**默认模型**；
3. 都没有时，交给 AstrBot 使用它自己的默认模型。

模型列表从哪里来：优先读取 AstrBot 的配置目录（`ASTRBOT_DATA_PATH` 下的 `cmd_config.json`），读不到时回退调用 AstrBot 的模型接口。列表为空时会直接提示 **未找到可用模型，请在 AstrBot 中配置后重试**。

| 情况 | 界面提示 |
|------|----------|
| AstrBot 未启动 | 「AstrBot 未启动或端口 6185 不可达，请先启动 AstrBot」 |
| API Key 不对 | 「AstrBot API Key 无效，请在「设置」→「AstrBot API Key」填写正确的 Key」 |
| 没有任何可用模型 | 「未找到可用模型，请在 AstrBot 中配置后重试」 |

你也可以在设置里配置**自己的**模型接入信息（API Key、Base URL、模型名、多个提供商），这些配置按账号保存，跨浏览器同步；留空时使用系统配置的令牌。

> 提示：模型越贵，费率倍数可能越高，单次对话消耗的积分也不同。同一次提问换个模型，花费可能差好几倍。

## 上下文与花费

每轮对话会带上：

| 组成 | 说明 |
|------|------|
| 系统提示词 | 根据当前**群类型**注入的角色定位（游戏群/学习群/工作群/兴趣群/生活群/社交群各不同），见 [群聊接入与群类型](group-setup) |
| 历史消息 | 该会话**最近 10 条**消息（一问一答都算） |
| 本次提问 | 你刚发的内容 |

因此：

- 对话越长，携带的上下文越多，**消耗的积分越多**（超过免费条数后按条加收，默认前 10 条免费、之后每条 +1）。
- 换了话题建议点 **新对话**，既省积分也让回答更聚焦。
- 带图片提问会按张数额外计费。
- 回复下方会提示本次消耗，例如「本次消耗 12 积分，剩余 488」。

> 提示：余额不足时面板会弹出提示条「积分不足（需 N 积分，当前 M），请升级权益或完成签到」，并提供 **去签到** 与 **升级权益** 两个快捷按钮。

## 人格（系统提示词）

「人格」决定 AI 用什么身份、什么风格说话，本质是一段系统提示词。

| 项目 | 说明 |
|------|------|
| 可配置内容 | 人格 ID、系统提示词、自定义报错回复、预设对话（JSON）、工具选择（JSON）、Skills 选择（JSON） |
| 可执行操作 | 新建人格、编辑、删除、**设为默认** |
| 谁能改 | **仅管理员**（读取人人可用，保存/删除/设为默认需要 ADMIN 角色） |
| 是否可按群绑定 | **不支持**。全系统只有一个人格作为默认；按群变化的是对话的系统提示词模板（依群类型），不是人格 |
| 保存位置 | 直接读写 AstrBot 的人格配置库，设为默认时会同步更新 AstrBot 配置 |
| 内置人格 | 系统不预置人格，现有记录来自 AstrBot 自身 |

怎么用：

1. 管理员在 AI 面板打开人格管理（或在首页相关入口进入），点 **+ 新建人格**。
2. 填写人格 ID 与系统提示词，例如「你是群里的技术答疑助手，只回答编程问题，语气简洁」。
3. 需要同一段开场时填写「预设对话」（JSON 格式，可选）。
4. 点 **保存**，然后在列表里点 **设为默认**，该人格成为全局默认。
5. 用户侧不需要任何操作，之后所有 AI 对话都会带上这个人格。

> 提示：人格设置与「群类型」是两套机制。人格管**身份与语气**（全局一份），群类型管**按群调整的提示词与推荐维度**。当前版本的界面里人格管理入口可能需要管理员协助开启，看不到时请联系管理员。

## TTS 语音合成

把 AI 回复念出来，需要已启动 GPT-SoVITS（默认 `http://localhost:8000`）。

1. 在任意一条 AI 回复下方点 **语音生成**（按钮会变成 **生成中...**）。
2. 生成完成后按钮变为 **播放语音**，下方出现播放器，点一下即可播放；再点一次可隐藏播放器。
3. 想换音色：点面板顶部的**语音合成角色**下拉，选择角色（默认提供 `Kisaki（妃那）` 与 `加藤惠`），切换后会提示「已切换到 xxx」。
4. 每个账号可以记住自己的音色选择。

计费与限制：

| 项目 | 规则 |
|------|------|
| 计费方式 | 按字符数，默认每 50 字符 1 积分，单次最低 2 积分 |
| 扣费时机 | **点击生成时先扣费**，再调用合成 |
| 长度限制 | 超过 500 字的文本会被截断（末尾加「……」） |
| 文本清洗 | Markdown 标记、emoji 等会被自动清理，只朗读正文 |
| 失败提示 | 「语音生成失败: <原因>」（常见原因是 GPT-SoVITS 未启动） |
| 退费 | 目前没有自动退费；确认失败却被扣费的，把明细里的 `relatedId` 给管理员处理 |
| 权限 | 需要登录，且账号未被禁止消费 |

> 提示：GPT-SoVITS 未启动时，登录页与后台「组件控制」都能看到它「未运行」。语音是可选能力，不影响文字对话。

## 让回答更好用的几个习惯

1. **先选消息再分析**比直接问「这群在聊啥」准确：选中的原文就是上下文。
2. 补充说明里写清目的，例如「我刚进群，帮我找共同话题」「只总结待办事项」。
3. 换话题就 **新对话**，避免旧上下文干扰并顺带省积分。
4. 群类型设对了，系统提示词与推荐维度都会更贴合，见 [群聊接入与群类型](group-setup)。
5. 需要结构化输出时直接要求，例如「用表格列出」「分点不超过 5 条」。

## 把回答转发到群聊

AI 的回答常常是要发回群里的（速览、结论、待办）。不用手动复制粘贴：

1. 鼠标移到任意一条消息上（AI 回复或你自己发的内容都有），点 **「转发到群」**。
2. 弹窗里选目标群：可以直接搜群名/群号，也可以手动填群号。**有该群可见性的用户都能发**。
3. 内容可以在弹窗里再改；默认勾选 **「清理 Markdown 标记」** —— QQ 不渲染 Markdown，
   去掉 `##`、`**`、代码围栏后更像正常消息（编辑框里仍是原文，清理只作用于发送内容）。
4. 点发送。以**机器人账号**的身份发出，与群聊面板里的发送框是同一套权限与限流。

几个细节：

| 细节 | 说明 |
|---|---|
| 谁发的 | 机器人在群里说话（不是你的 QQ 号）；发送成功后消息由 NapCat 回传入库，群聊面板能看到 |
| 限流 | 每分钟 10 次（与群聊面板共用），超了会提示稍后再试 |
| 长度 | 单条上限 2000 字；超出会给出 **「分 N 条发送」**，按行断句，不是硬切 |
| 失败 | NapCat 未登录 / 无该群权限 / 群号不存在都会明确报错，不会静默丢弃 |
| 附件 | 这里只转发**文字**；图片、文件请到群聊面板用发送框的附件按钮 |

> 提示：转发的是**纯文本**。表格、代码块这类内容清理后可能变形，必要时在弹窗里手动调一下再发。

## 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 面板显示「离线」 | AstrBot 未启动，管理员在后台「组件控制」启动 |
| 一直转圈没有回复 | 模型侧超时或令牌无效；先确认在线状态，再看 [AI 摘要](ai-summary) 的排查章节 |
| 提示积分不足 | 见 [积分体系](credits)：签到或购买积分 |
| 回复里出现「抱歉，无法分析…」 | 模型返回了空内容，系统用兜底文案替代；这次**仍会计费**，可让管理员核对处理 |
| 语音生成失败 | GPT-SoVITS 未启动或参考音频/模型路径无效，请管理员按 [系统配置](system-config) 检查 |
| 历史会话不见了 | 会话按账号保存，切换账号或换了浏览器看不到对方的会话；删除的会话不可恢复 |
| 想换个模型试 | 面板顶部模型下拉切换；没有可选模型说明 AstrBot 侧没有启用任何模型 |
