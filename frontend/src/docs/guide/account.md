这一页管的是「你自己的账号」：改昵称、换密码、绑定/解绑 QQ、忘记密码怎么办、怎么安全退出。

## 个人中心在哪

1. 点击左侧侧边栏**底部的头像/用户名**，打开用户菜单。
2. 选择进入 **用户中心**，页面顶部有四个标签页：

| 标签页 | 里面有什么 |
|--------|------------|
| 数据概览 | 我的消息趋势、活跃群聊排行 TOP5、消息类型分布、AI 对话趋势 |
| 个人信息 | 基本信息、QQ绑定、账号安全（改密码） |
| 用量管理 | 积分余额、签到、用量明细、积分趋势 |
| 订阅管理 | 套餐、购买、我的订单、退款与申诉 |

> 提示：侧边栏顶部的积分徽章也可以直接跳到「用量管理」。

## 修改资料

1. 进入 **用户中心 → 个人信息**。
2. 在「基本信息」区域点击 **编辑资料**。
3. 弹窗里可修改：

   | 字段 | 说明 |
   |------|------|
   | 昵称 | 必填，显示在页面各处的名字 |
   | 邮箱 | 选填，填写时会做格式校验，格式不对会提示「邮箱格式不正确」 |

4. 点击 **保存**（保存中会显示「保存中...」）。

> 提示：如果账号不是你自己注册的（管理员代建），昵称可能是账号名，改一次即可。

## QQ 绑定

**不绑定 QQ 就看不到任何消息**，这是最容易漏的一步。

### 添加绑定

1. **用户中心 → 个人信息 → QQ绑定**，点击 **添加绑定**。
2. 在「绑定QQ账号」窗口输入要绑定的 QQ 号（5~11 位数字，格式不对会提示「请输入正确的QQ号」）。
3. 点击 **发送验证码**。系统会通过**机器人（NapCat）向该 QQ 号发送一条私信**，内容形如：

   ```text
   【铃音QQ助手】您正在进行QQ账号绑定验证，验证码为：123456
   该验证码 5 分钟内有效，请勿泄露给他人。
   如非本人操作，请忽略此消息。
   ```

4. 打开手机 QQ，找到这个机器人号码发来的消息（也就是「自发消息」），取 6 位验证码填入。
5. 点击 **确认绑定**，提示「绑定成功」即完成。

### 绑定规则

| 规则 | 说明 |
|------|------|
| 验证码长度 | 6 位数字 |
| 有效期 | **5 分钟**，过期提示「验证码已过期，请重新获取」 |
| 发送频率 | 每个 QQ 号**每天最多 10 次**；发送后界面有 60 秒倒计时 |
| 错误次数 | 同一验证码连续输错 10 次会作废，需重新获取 |
| 唯一性 | **一个 QQ 号只能被一个账号绑定**；已被别人绑定时提示「该QQ号已被其他用户绑定」 |
| 重复绑定 | 同一账号重复绑定同一个 QQ 会提示「该QQ号已绑定」 |
| 多绑定 | 一个账号可以绑定**多个** QQ 号，群聊与消息按 QQ 号分组展示 |
| 默认账号 | 绑定的第一个 QQ 会自动成为默认账号；有多个时可手动切换默认 |

### 设为默认 / 解绑

| 操作 | 怎么做 | 结果 |
|------|--------|------|
| 设为默认 | 在绑定列表里点星标按钮（`设为默认`） | 提示「已设为默认」，该行出现「默认」徽标 |
| 解绑 | 点解绑按钮，确认「确定解绑QQ <号码> 吗？」 | 提示「解绑成功」；解绑默认账号时会自动把剩下的第一个设为默认 |

> 提示：解绑只会解除关联，**不会删除已入库的消息**。解绑后该 QQ 的消息不再展示给你，重新绑定同一个人即可恢复查看。

## 修改密码

1. **用户中心 → 个人信息 → 账号安全**，点击 **修改密码**。
2. 填写 **当前密码**、**新密码**、**确认新密码**（两次不一致会即时提示「两次输入的密码不一致」）。
3. 点击 **确认修改**。

新密码的硬性规则（后端强校验，不符合会被拒绝）：

| 规则 | 要求 |
|------|------|
| 长度 | **8~64 位** |
| 字符 | 必须**同时包含大写字母、小写字母与数字** |
| 可用符号 | 仅允许 `@ $ ! % * ? &` 这几类符号（其它符号会校验失败） |
| 失败提示 | 「新密码强度不足，至少 8 位且包含大小写字母与数字」 |
| 旧密码错 | 提示「旧密码错误」 |

> 提示：修改密码成功后，**当前登录态会立即失效**，需要用新密码重新登录一次。这是为了保护账号——如果密码是被别人改的，他也会被踢下线。

## 忘记密码怎么办

系统**没有绑定邮箱/手机，不支持自助找回**。登录页点 **忘记密码？** 会看到官方指引，实际处理方式是：

1. 联系系统管理员。
2. 管理员登录后台 → **用户管理** → 找到你的账号 → 点击 **重置密码**。
3. 管理员按规则设置新密码：**8-64 位，且同时包含大写字母、小写字母与数字**（不符合会提示「密码不符合规则：需 8-64 位且含大小写字母与数字」）。
4. 重置成功后，**你原来的登录状态立即失效**，用新密码重新登录即可。

如果你是管理员本人且忘了密码：

- 请用**另一个管理员账号**登录后台，在「用户管理」里重置你的密码；
- 或者直接在部署机器上按 [系统配置](system-config) 的说明，通过环境变量 `ADMIN_INIT_PASSWORD` 与数据库初始化的方式处理；
- 已登录状态下改密码不需要走这条路：直接 **个人中心 → 修改密码**。

## 登录与「记住我」

| 项目 | 说明 |
|------|------|
| 登录字段 | 账号 + 密码，按 `Enter` 可直接提交 |
| 记住我 | 勾选 **记住我（30 天免登录）** 后，登录态保持 **30 天** |
| 不勾选 | 登录态默认保持 **24 小时**，过期需重新登录 |
| 登录失败 | 提示「用户名或密码错误」；账号被禁用时提示「账号已被禁用」 |
| 登录频率 | 同一 IP + 账号每分钟最多尝试 5 次，超出提示「登录尝试过于频繁，请 1 分钟后再试」 |
| 登录态存储 | 由浏览器的 HttpOnly Cookie 承载，脚本无法读取，比存在本地存储更安全 |
| 注册开关 | 若提示「注册暂未开放」，说明管理员关闭了自助注册，请让管理员建号 |

> 提示：管理员可在 `backend/.env` 中通过 `JWT_REMEMBER_ME_EXPIRATION` 调整「记住我」的时长（毫秒）。公共电脑上请不要勾选。

## 退出登录

1. 点击侧边栏底部头像打开用户菜单，选择 **退出登录**。
2. 在确认框「确定要退出登录吗？」点击 **确认**。
3. 系统会注销当前登录令牌并清除登录态，回到登录页。

管理员在后台的顶栏也有 **退出登录** 按钮，作用相同。

> 提示：退出登录**不会**停止 NapCat / AstrBot / GPT-SoVITS 等组件。组件的启停由管理员在后台「组件控制」里操作。

## 账号安全建议

1. 首次登录后立即改掉初始密码，尤其是不勾「记住我」的习惯机器。
2. 密码不要与 QQ 密码相同，也不要多个平台复用。
3. 只在确认是自己的设备上勾选「记住我」；公共设备用完主动退出。
4. 定期查看「用量管理」的积分明细，异常的扣费能第一时间发现。
5. 把账号借给别人前先想清楚：绑定在他名下的 QQ 消息对你可见，反之亦然。

## 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 提示「该QQ号已被其他用户绑定」 | 一个 QQ 只能绑一个账号；确认后请联系管理员处理 |
| 收不到验证码私信 | 确认机器人 QQ 在线（NapCat 已登录），并检查是否已达当日 10 次上限 |
| 改完密码就被踢到登录页 | 正常行为，用新密码重新登录即可 |
| 登录页一直提示「登录尝试过于频繁」 | 等 1 分钟再试，或确认账号密码无误后一次成功 |
| 用户中心找不到「退出登录」 | 退出入口在侧边栏底部头像菜单与后台顶栏，不在用户中心页面内 |
| 绑定成功但看不到群 | 机器人 QQ 需在该群里且收到过消息，见 [群聊接入与群类型](group-setup) |
