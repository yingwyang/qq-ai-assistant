这一页讲「花钱的部分」：有哪些档位、怎么买、订单状态什么意思、退款与申诉怎么走。所有价格与积分数都由管理员在后台可配，**以订阅页上显示的数字为准**。

## 页面在哪

进入 **用户中心 → 订阅管理**。页面从上到下是：

1. 顶部：**订阅与发票** 入口、当前积分余额（可点进用量管理）、**当前方案** 卡片（方案名、权益摘要、到期时间或「永久免费」）。
2. 最近消费与剩余天数提示，右侧 **升级权益** 按钮。
3. **按档购买，立即到账** 分组：直购积分档位卡片。
4. **会员月卡** 分组：小月卡、大月卡卡片（副标题「30 天权益，超值更省」）。
5. **我的订单**：筛选、订单表格与分页（每页 10 条）。

## 直购积分档位

买断式积分包，确认收款后积分直接入账，不改变订阅等级：

| 代码（内部标识） | 界面名称 | 默认价格 | 到账积分 |
|------|----------|----------|----------|
| `LITE` | 直购积分·2000 | ¥9.9 | 2000 |
| `PRO` | 直购积分·4000 | ¥59 | 4000 |
| `PROPLUS` | 直购积分·12000 | ¥219 | 12000 |
| `ULTRA` | 直购积分·40000 | ¥629 | 40000 |
| `MEGA` | 直购积分·100000 | ¥648 | 100000 |

- **界面名称按到账积分生成**（「直购积分·N」），价格与积分全部可在后台「规则配置 → 直购积分」调整，
  改完立即生效；卡片上的名称、价格、权益文案会一起变。
- 权益文案（如「全模型支持」「优先响应」「高优先级队列」）仅作说明展示；实际能力取决于 AstrBot 侧的模型接入。
- **直购积分不会过期**，长期有效。

## 月卡档位

| 代码（内部标识） | 界面名称 | 默认价格 | 时长 | 到账积分 | 每日签到额外 | 专属折扣 |
|------|----------|----------|------|----------|--------------|----------|
| `SMALL_MONTH_CARD` | 小月卡 | ¥30 | 30 天 | 3000 | **+100** | 9 折 |
| `LARGE_MONTH_CARD` | 大月卡 | ¥68 | 30 天 | 8000 | **+300** | 8 折 |
| 双持 | 全功能版（小月卡 + 大月卡） | 两张卡合计 ¥98 | 30 天 | 11000（两笔分别到账） | **+400**（100 + 300 叠加） | 见下方提示 |

> 上表是**出厂默认值**。价格、赠送积分、每日签到加成、折扣现在都在后台「规则配置」里可改
> （直购积分 → 直购积分区块；月卡 → 会员月卡区块），**以订阅页显示的数字为准**。
> 双持的每日加成不单独配置，永远是「小月卡 + 大月卡」两张卡的数值相加。

月卡关键规则：

1. **重复购买限制**：同一种月卡不能重复购买，会提示「您已购买同档位月卡（有效期至 X），同种月卡不可重复购买。如需续期请联系管理员。」；同时持有大小月卡时再买会提示「您已同时拥有大小月卡（全功能版），无需再购买。」
2. **双持叠加**：同时持有两卡时，订阅等级变为**全功能版**，每日签到额外积分按两张卡之和发放（默认 **+400**），计费折扣按系统「双持（ALL）折扣」计算（默认 **7 折**）。
3. **每日额外积分随签到发放**：不再在购买时一次性发放，也不随登录自动到账；必须每天点签到才能拿到那 +100 / +300 / +400。
4. **到期处理**：月卡到期后，系统每天凌晨 2 点会把到期的订单标记为「已过期」，订阅等级回退为免费版。

> 提示：订阅页在双持状态下合并展示权益时，折扣文案可能显示为两卡中较优的一档（如「专属折扣 8 折」），而实际扣费按系统的双持折扣（默认 7 折）执行。以「用量明细」里的实际扣费为准。

## 购买流程

1. 在 **订阅管理** 找到目标档位卡片（月卡显示 `¥价格/30天`，直购显示 `¥价格`）。
2. 点击 **立即购买**，弹出确认框：

   ```text
   确认购买 小月卡？
   ¥30.0 / 30天，获得 3000 积分
   ```

3. 确认后订单被创建，状态为**待支付**，页面提示：**订单已创建，待管理员确认到账后发放权益**。
4. 按页面/管理员提示完成线下付款（系统采用人工确认收款方式，**没有在线支付通道**）。
5. 管理员在后台 **订单管理** 里点 **确认收款**，订单变为**已支付**，积分与权益同时到账。
6. 到账后回到订阅页，**当前方案**、积分余额、每日签到加成都会立刻更新。

防护机制：

| 机制 | 说明 |
|------|------|
| 同档位短期重复提交 | 60 秒内对同一档位重复下单会直接返回已有订单，不会重复扣款 |
| 同档位月卡重复购买 | 直接被拒绝并给出提示 |
| 订单详情 | 订单号可点击，能看到完整快照与时间轴，便于对账 |

## 订单状态含义

「我的订单」的状态筛选下拉里可以按这 7 种状态过滤：

| 状态 | 界面文案 | 含义 | 你能做什么 |
|------|----------|------|------------|
| `PENDING` | 待支付 / 待确认 | 订单已创建，**等待管理员确认收款** | 查看详情、取消 |
| `PAID` | 已支付 | 已确认到账，积分与权益已发放 | 查看详情、申请退款、纠纷申诉 |
| `PENDING_REFUND` | 退款审批中 | 退款申请已提交，等待管理员审批 | 只能查看详情并等待 |
| `DISPUTED` | 纠纷中 | 已提交申诉，等待管理员处理 | 只能查看详情并等待 |
| `REFUNDED` | 已退款 | 退款已完成，积分已按比例扣回 | 仅查看详情 |
| `CANCELLED` | 已取消 | 订单被取消/作废 | 仅查看详情 |
| `EXPIRED` | 已过期 | 月卡到期后由系统自动置入 | 仅查看详情 |

几个容易误解的点：

- 「待支付」不等于失败，它只表示**还没确认收款**。
- **未支付订单不会自动过期**，它会一直停在待支付，你可以手动取消。
- 订单表格里的状态列文案与筛选下拉略有差异（同一状态可能写「待确认」），含义相同。
- 订单详情抽屉里有 6 块信息：订单基础信息、套餐快照、支付与权益、退款信息、备注/其他、订单时间轴，「关联流水」还能一键跳到对应的积分明细。

## 取消订单

只有**待支付**状态的订单可以取消：

1. 在订单行点 **取消**。
2. 确认框「确定取消订单 <订单号>？取消后无法恢复。」
3. 成功后订单变为「已取消」。

## 申请退款

1. 找到状态为 **已支付** 的订单，点 **申请退款**（订单详情抽屉底部也有同名按钮）。
2. 弹窗「申请退款」会显示订单号、套餐、金额。
3. 填写 **退款原因**，**至少 5 个字**，不足会提示「请填写至少5个字的退款原因」。
4. 点 **确认申请退款**，提示「退款申请已提交」，订单状态变为**退款审批中**。
5. 等管理员在后台 **退款审批** 处理：

   | 管理员的处理 | 结果 |
   |--------------|------|
   | 同意退款 | **全额退款**，订单变「已退款」，并按比例扣回已发放的积分；月卡的剩余天数按比例回退 |
   | 驳回 | 订单恢复为「已支付」，并会记录驳回原因 |

6. 退款到账方式与购买方式一致（线下），请与管理员确认。

> 提示：管理员也可以按比例做**部分退款**（退款比例 0~1，默认全额）。部分退款同样会按比例扣回积分与月卡天数。

## 纠纷申诉

对处理结果不满意、或订单迟迟没有进展时，可以发起纠纷：

1. 找到状态为 **已支付** 的订单，点 **纠纷申诉**（或订单详情抽屉底部按钮）。
2. 填写 **申诉原因**，同样**至少 5 个字**。
3. 点 **确认申诉**，提示「纠纷申诉已提交，请等待管理员处理」，订单状态变为**纠纷中**。
4. 管理员在后台 **纠纷处理** 页面处理，处理方式只有两种：

   | 处理方式 | 结果 |
   |----------|------|
   | 同意退款（全额退款） | 订单变「已退款」，积分按比例扣回 |
   | 驳回纠纷（恢复已支付状态） | 订单恢复「已支付」，权益保持 |

5. 管理员处理时会填写处理说明，处理完成后可在订单详情时间轴里看到记录。

> 提示：纠纷与退款是两条并行入口。已经处于「退款审批中」或「纠纷中」的订单，需要等管理员处理完才能再操作，不要重复提交。

## 管理员补单（管理员视角）

用户付款后订单一直没到账、或需要线下赠送时，管理员可用补单：

1. 后台 **订单管理** → 右上角 **+ 补单**。
2. 填写：

   | 字段 | 说明 |
   |------|------|
   | 用户 ID | 必填，目标用户的数字 ID |
   | 套餐 | 必填，可选各直购积分档位、小月卡、大月卡 |
   | 自定义价格（分） | 选填，单位是**分**；留空用套餐默认价 |
   | 自定义积分 | 选填，留空用套餐默认积分 |
   | 时长（天） | 选填，留空用套餐默认时长 |
   | 自定义订单号 | 选填，留空自动生成 |
   | 备注 | 选填 |

3. 点 **确认补单**。系统**直接创建「已支付」订单**并立即发放积分，提示「补单成功：<订单号> 已直接支付」。
4. 补单同样遵守月卡的叠加与升级逻辑：给小月卡用户补大月卡，会直接升为全功能版。

## 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 付款后订单一直是「待支付」 | 需要管理员在后台点「确认收款」，请联系管理员 |
| 买了月卡但签到没有加成 | 确认订单状态是「已支付」，且当天已签到；加成与签到同一次到账 |
| 想再买一张同样的小月卡 | 同档位不可重复购买，需要续期请联系管理员 |
| 申请退款按钮点不动 | 只有「已支付」订单能申请退款；其他状态需先等管理员处理 |
| 退款后积分变成负数 | 扣回按比例计算并做了余额下限保护，不会出现负余额；若数字异常请联系管理员 |
| 订单「已过期」但月卡还在用 | 「已过期」是订单到期标记，不代表立即失效；权益以到期时间为准 |
| 能开发票吗 | 系统当前不提供发票功能，需要发票请与部署方线下协商 |
| 订单号有什么 | 订单号是对账凭据，点击可复制；查退款、找管理员时请提供订单号 |
