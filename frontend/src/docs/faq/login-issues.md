# 登录问题

## 忘记管理员密码

如果忘记管理员密码，可以通过以下方式重置：

1. 停止后端服务
2. 在数据库中执行：
   ```sql
   UPDATE users SET password = '新密码的BCrypt哈希' WHERE username = 'admin';
   ```
3. 重启后端服务

## 登录后跳转回登录页

**可能原因**：Token 过期或无效

**解决方法**：
1. 清除浏览器 localStorage 中的 `auth_token`
2. 重新登录
3. 如果问题持续，检查后端服务是否正常运行

## 提示"无权限访问"

**可能原因**：普通用户尝试访问管理员页面

**解决方法**：
- 确认账户角色是否为 ADMIN
- 联系管理员提升权限
- 检查 `user_role` 在 localStorage 中是否正确

## 页面白屏

**可能原因**：前端资源加载失败

**解决方法**：
1. 检查浏览器 Console 是否有报错
2. 清除浏览器缓存后刷新
3. 确认前端服务正常运行
