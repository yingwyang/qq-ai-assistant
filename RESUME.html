4.1 铃音QQ对话 — 跨端智能聊天辅助系统（独立开发）

技术栈：SpringBoot 3.2.0 + Vue3 + MySQL 8.0 + MinIO + WebSocket + NapCat + AstrBot + GPT-SoVITS

项目描述：基于 NapCat 监听 QQ 消息，通过 AstrBot 实现 AI 智能总结，集成 GPT-SoVITS 语音合成的跨端智能聊天辅助平台。支持多用户/多QQ绑定、消息实时推送、智能体人格管理、AI 多提供商切换等功能。

核心职责与成果：

  • 架构设计：采用前后端分离架构，设计 MySQL 按月份分表策略，解决海量消息存储性能问题；制定跨语言（Java/JS/Python）组件通信规范，实现多组件协同可控。
  • 功能开发：实现 QQ 二维码登录、消息实时监听/存储/展示、AI 消息总结、组件一键启停等核心功能；封装 RESTful API 与 WebSocket 实时推送，完成前后端联调。
  • 问题解决：修复图片消息解析异常、跨平台组件启停兼容等问题；优化消息分页加载逻辑，提升前端交互体验；实现 JWT 黑名单机制和用户级权限隔离。
  • 交付成果：输出完整的部署文档、API 接口文档，实现系统本地一键部署，达成毕业设计全流程交付要求。

    • 技术亮点：

    • Spring Security + JWT 实现无状态鉴权，支持 Token 主动失效
    • Caffeine 缓存实现 Token 黑名单，支持改密码/注销时强制失效旧 Token
    • 原生 SQL 批量查询优化，解决 N+1 查询问题
    • WebSocket 实时推送，消息到达即展示
    • 多提供商 AI 配置 JSON 化存储，支持热切换
